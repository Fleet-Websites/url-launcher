### Open Source Assets — Fonts, Images, Audio, Game Assets

| URL | Description |
|-----|-------------|
| https://freesound.org | Freesound — 600,000+ Creative Commons licensed audio samples; collaborative community database |
| https://openverse.org | Openverse (WordPress) — search images and music licensed under Creative Commons from many sources worldwide |
| https://www.flickr.com/commons | Flickr Commons — cultural institutions posting images with no copyright restrictions; Smithsonian, Internet Archive, and others |
| https://thenounproject.com | The Noun Project — simple CC-licensed icons for visual communication; most free with attribution |
| https://kenney.nl | Kenney.nl — massive library of free public domain game assets: 2D, 3D, UI, fonts, and audio; CC0 |

| https://www.fontsquirrel.com | Font Squirrel — handpicked free fonts licensed for commercial use |
| https://pixabay.com | Pixabay — royalty-free images, illustrations, videos, and music; no attribution required |
| https://unsplash.com | Unsplash — high-resolution photos free for commercial and non-commercial use |
| https://www.pexels.com | Pexels — curated free stock photos and videos; CC0 license |
| https://openclipart.org | OpenClipart — SVG clip art all released as CC0/public domain |
| https://www.gutenberg.org | Project Gutenberg — 70,000+ free eBooks with expired copyright; excellent source for public domain text |
